# Безопасность

## 1. Поверхность атаки

В production нет собственного SSH, Nginx, Docker или открытого порта на VPS. Публичным является только HTTPS endpoint Cloudflare Worker.

## 2. Два независимых секрета

Webhook защищается:

1. точным секретным path;
2. `crm_token` в теле МегаФон webhook.

Один секрет не заменяет другой.

## 3. Секреты

Не хранить в Git:

- `MEGAFON_CRM_TOKEN`;
- `WEBHOOK_SECRET_PATH`;
- `INTRASERVICE_LOGIN`;
- `INTRASERVICE_PASSWORD`;
- любые API tokens.

`.dev.vars*` и `.env*` исключены из Git.

## 4. Ограничение входного запроса

Worker проверяет:

- метод `POST`;
- точный путь;
- размер payload не более 64 KiB;
- поддерживаемый `Content-Type` (`application/x-www-form-urlencoded` или JSON);
- корректный body;
- `crm_token`;
- `cmd=history`;
- `type=in`;
- `status=success`;
- `duration > 10`;
- наличие `callid` и `user`.

## 5. SSRF и запись разговора

Worker не скачивает запись разговора. В IntraService передаётся только HTTPS URL, полученный из МегаФон.

## 6. Логи

Нельзя писать в логи:

- CRM token;
- IntraService password;
- Authorization header;
- полный webhook payload.

Логируются только технические идентификаторы и типы ошибок.

## 7. Права IntraService

Для текущей конфигурации заявка создаётся с:

- сервисом `619` («Звонки»);
- типом `1024`;
- приоритетом `11` («Низкий»);
- статусом `29` («Выполнена»);
- заявителем `1744` («Служебный аккаунт», системная роль «Клиент»).

`ExecutorIds` не передаётся, потому что конкретный ID исполнителя не подтверждён в текущем проекте.

Учётная запись, указанная в `INTRASERVICE_LOGIN`/`INTRASERVICE_PASSWORD`, должна иметь право создать такую заявку и указать `CreatorId=1744`. Это необходимо проверить фактическим API-запросом.

## 8. Персональные данные

D1 хранит технические данные, необходимые для идемпотентности и аудита: номер клиента, идентификатор оператора ВАТС, время звонка, длительность и ссылку на запись. Сам файл записи не скачивается и не копируется в D1.

Период хранения D1 должен быть определён отдельно согласно вашей внутренней политике.
